# Potències i operacions combinades · 1r ESO

Aplicació web per aprendre i practicar **operacions combinades** i **propietats de les potències** (situació d'aprenentatge «Qui és l'MVP?»).

### 👉 [Obre l'aplicació](https://albertcid-pa.github.io/potencies-operacions-combinades/)

- Web: https://albertcid-pa.github.io/potencies-operacions-combinades/
- Directament a la pràctica: https://albertcid-pa.github.io/potencies-operacions-combinades/#practica

## Aprèn
- Ordre de les operacions (jerarquia interactiva amb els símbols de cada operació).
- Potències, arrels quadrades i propietats de les potències.
- Exemples resolts pas a pas.
- «Resol la teva operació»: l'alumne escriu una operació en un editor visual i la veu resolta pas a pas.

## Practica
- Exercicis generats a l'atzar, sempre resolubles amb nombres naturals (resultat final entre 1 i 50 a les operacions combinades).
- Tipus: operacions combinades, propietats de les potències o barreja (amb variants).
- Tres nivells: Bàsic, Mitjà i Avançat, amb exemples de cada nivell abans de començar.
- Mode **pas a pas**: l'alumne tria les operacions que es poden fer (diverses alhora en una mateixa línia, com a la llibreta) i n'escriu els resultats; l'app corregeix cada línia i explica els errors d'ordre.
- Mode **només el resultat**, amb pistes progressives.
- Marcador de bàsquet amb cistelles, ratxa i rècord.

## Tecnologia
Fitxers estàtics (`index.html`, `style.css`, `app.js`). Fa servir [KaTeX](https://katex.org) per escriure les matemàtiques i [MathLive](https://cortexjs.io/mathlive/) per a l'editor d'operacions, tots dos carregats des de CDN. Funciona a l'ordinador i al mòbil.

## Provar-la a l'ordinador
Obre `index.html` amb el navegador.
